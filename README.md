# Bio-Sayegh
## Implementar campañas de concienciación prácticas apoyadas en un aplicativo web pedagógico, donde los estudiantes interactúen con contenidos de biodiversidad para reducir la presencia de residuos mal gestionados en las áreas comunes del Colegio San Alberto Magno en el ciclo 2026.
## Caracteristicas
* *Ambiental*
* *Ecologico*
* *Escolar*
##  Tecnologías Utilizadas
* **HTML5** - Estructura semántica.
* **CSS3** - Estilos y maquetación.
* **JavaScript (ES6+)** - Lógica e interactividad.
